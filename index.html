Acesso à Câmara Bloqueado

O navegador não conseguiu aceder à tua câmara. Isto é muito comum quando executas o projeto dentro de plataformas de simulação (como este painel lateral).

Solução 1: Usar o Modo de Simulação

Podes simular os sinais da mão clicando nos dedos sem precisar de câmara. Perfeito para testar agora mesmo!

Solução 2: Executar no teu computador

Para usar a câmara verdadeira, clica no ícone de exportar/descarregar código no topo direito deste ecrã, guarda o ficheiro como index.html e abre-o diretamente no teu navegador Chrome, Edge ou Safari!
